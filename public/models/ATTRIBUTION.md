# eFootball training player

`efootball-forward.glb` is generated by `scripts/generate-efootball-player.mjs`.
Human topology, male/athletic morph data and skinning weights: MakeHuman Community,
CC0 1.0. No MakeHuman application code is included.
Source: https://github.com/makehumancommunity/makehuman/tree/a8bc2d54ff0ac92e78ff71431b1023eda42bf482/makehuman/data
Asset license: https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md

Custom changes: athletic shape, 17-joint rig, navy/red football kit, jersey texture,
swept hair, beard, eyes, boots and material batching. The supplied eFootball cover
is a visual reference; this model is an approximation, not a scanned likeness.
The GLB includes the skeleton and can be imported into Blender for further editing.
