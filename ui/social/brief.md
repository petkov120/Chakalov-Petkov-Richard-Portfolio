# Social interaction

## Story

A person finds something meaningful, responds with intention, and keeps it for later without losing their place.

## Recommended flow

1. `01-feed` — one strong post with enough author and context information.
2. `02-detail` — focused media or post view.
3. `03-response` — reaction, reply, or save action with clear feedback.
4. `04-collection` — optional saved destination or confirmation.

## Interaction to record

Open a post → react or save → receive feedback → return to the same feed position.

## Design test

- Content remains visually stronger than interface controls.
- Feedback feels human but does not become playful noise.
- The user never loses their position in the feed.
