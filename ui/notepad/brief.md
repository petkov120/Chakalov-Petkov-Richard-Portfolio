# Notepad interaction

## Story

A thought is captured before it disappears, then turned into something findable and useful.

## Recommended flow

1. `01-notes` — recent notes with a clear visual hierarchy.
2. `02-quick-capture` — immediate writing surface with keyboard-safe controls.
3. `03-organise` — lightweight tag, pin, or collection choice.
4. `04-saved` — the note returns to the list in the expected place.

## Interaction to record

Create a note → write a short thought → add one organising property → save.

## Design test

- Writing is always the primary action.
- Formatting controls do not dominate the canvas.
- Saving feels trustworthy without interrupting the thought.
